# Abdeldjabbar ABBA — Portfolio Website

A responsive, single-page portfolio based on the visual style and information in Abdeldjabbar's CV.

## Run it locally

1. Extract the ZIP (if downloaded as a ZIP).
2. Open `index.html` in a browser.

The site is static: no build tools, package manager, or server are required. An internet connection is only needed to load the optional Google Fonts; system font fallbacks are included.

## Publish it

This folder can be deployed to any static hosting provider, for example GitHub Pages, Netlify, or Render Static Sites. Upload the contents of this folder and use `index.html` as the entry page.

## Customize it

- Edit the text directly in `index.html`.
- The colors are declared near the top of the `<style>` block as CSS variables (`--paper`, `--navy`, `--blue`, `--blue-soft`, and related values).
- The contact details currently match the supplied CV.
- Social profile URLs were not present in the CV, so no guessed GitHub, LinkedIn, Telegram, or other profile links have been added.

## Palette sampled from the CV

- Warm off-white: `#F9F7F7`
- Deep navy: `#112D4E`
- Muted blue: `#3F72AF`
- Pale blue: `#DBE2EF`
- Main text: `#24364F`

## Notes

- The charts and interface thumbnails inside the project cards are illustrative design elements, not actual product screenshots or model-result claims.
- The skill groups preserve the CV's distinctions between independent use, use in projects, introductory exposure, and topics currently being studied.
